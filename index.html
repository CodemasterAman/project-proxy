/ everything in one place

One tool for the whole testing picture.

Complexity tells you how much there is to test. Mutation testing tells you how good your tests already are. susgrade brings both together into a single risk score.

/ 01 — complexity, live · python

Paste code. Watch the risk light up.

susgrade analyses Python and JavaScript, straight from each language's own syntax tree. Every function gets an exact path-count — the bigger and hotter the bar, the more branches hide inside, and the more tests it takes to cover them.

/ 02 — mutation testing · python

Now score how good your tests are.

Complexity shows how much there is to test. Mutation testing shows whether your tests actually catch bugs: susgrade makes tiny changes — mutants — to your code and re-runs your tests against each. A mutant your tests catch is killed; one that slips through survives, and every survivor is a real gap worth a test.

Runs entirely in your browser — no backend, no setup. The first run loads a small Python runtime (cached afterwards), then it's instant. Your tests import the code under test from subject.

/ 03 — risk report · python

The one number: what to test next.

This is the whole point of susgrade. It fuses the two signals — how complex each function is, and how well your tests actually cover it — into a single score per function: risk = complexity × (1 − mutation score). The function that's both complex and weakly tested rises to the top, so you always know where your next test belongs.

Runs entirely in your browser — no backend. It measures complexity and runs mutation testing together, then ranks every function by risk.

/ 04 — ci integration · quality gate

Make risk fail the build.

susgrade ships a command-line gate — the same three signals, wired to an exit code. Point it at your code in CI and the build turns red the moment a function gets too branchy, a suite stops catching mutants, or risk climbs past the line you drew. Pick your setup and copy a config that's ready to drop in.

The config is generated right here, on this page — nothing to install just to look. The gate itself runs the susgrade command from the backend/ package inside your pipeline.

/ 02 — read it

        
Three numbers, no PhD required.

      

      

        

          
/ 01
Count the paths

          
Every if, for, and or except adds one more way through a function. susgrade counts them exactly, from Python's own syntax tree.

        

        

          
/ 02
Read the colour

          
Green is calm, red is spicy. A function in the red has so many branches that a handful of tests will almost certainly leave gaps.

        

        

          
/ 03
Test where it's hot

          
Start with the gnarliest function, not the first one you see. That's where bugs hide and where each new test buys you the most safety.

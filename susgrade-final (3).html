/ 02 — mutation testing · python

Now score how good your tests are.

Complexity shows how much there is to test. Mutation testing shows whether your tests actually catch bugs: susgrade makes tiny changes — mutants — to your code and re-runs your tests against each. A mutant your tests catch is killed; one that slips through survives, and every survivor is a real gap worth a test.

Runs entirely in your browser — no backend, no setup. The first run loads a small Python runtime (cached afterwards), then it's instant. Your tests import the code under test from subject.

/ 01

Count the paths

Every if, for, and or except adds one more way through a function. susgrade counts them exactly, from Python's own syntax tree.

/ 02

Read the colour

Green is calm, red is spicy. A function in the red has so many branches that a handful of tests will almost certainly leave gaps.

/ 03

Test where it's hot

Start with the gnarliest function, not the first one you see. That's where bugs hide and where each new test buys you the most safety.
